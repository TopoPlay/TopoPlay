Fossil variety sprites

PNG files in this folder join the Fossil-mode random selection. Use genuine
RGBA transparency around AND between bones; opaque backgrounds become diggable
content. Files should contain one complete skeleton or a separated grouping.
The fallback image at ../dinotrex.png is also included in the selection.

A round chooses one image, an angle and a fitted scale of 65–100%. The selected
image remains fixed during digging. Toggle Fossil mode off and on for a new
round. Immediate image repeats are avoided when another readable image exists.
The group image exposes its smaller skeletons independently through the normal
sand reveal mask; it remains one image and one buried reference plane.

Generated artwork and credits: see ASSETS.md in the repository root and
docs/assets/fossil-variety-provenance.json.
These are stylized illustrations, not scientific reconstruction diagrams.
